# EtherCAT from Scratch

[中文](README.md) | English

How robot joints talk and stay in sync, read through SOEM on a virtual line. Each episode goes in five steps: watch the video → read → play with the lab page → code it in the dojo → do the real assignment. Your code lives in real files on your computer, and the tests run with the real toolchain. The exercises, tests and code are original.

## Getting started

1. Install Node.js 22.19 or newer: <https://nodejs.org/> (the local runner uses it).
2. 
3. In this folder, run:

   ```bash
   npm start
   ```

4. Open the link printed in the terminal (the browser opens on its own) to reach the **course home**. Videos can be watched chapter by chapter, and your progress is saved in the browser. The 中 / EN button switches the language; the default follows your browser.

 Write in the browser or in your editor; the two stay in sync.

Video files are large and are not in the git repository; they are published on the Releases page. Download one and put it at `content/epNN/video.mp4`.

## Safety

The runner executes code on your computer, so it listens only on 127.0.0.1, generates a random token at every start that web requests must carry, and checks the Host and Origin headers to block DNS rebinding attacks.

## Layout

| Path | Contents |
|---|---|
| `server.ts` | The local runner: serves the pages, reads and writes your code files, runs the tests (`npm start`) |
| `lib/runner.ts`, `lib/langs/` | The runner core, and one driver per language (Go, TypeScript, Python, Rust) |
| `web/js/course.js`, `course.en.js` | Course data: each episode's steps, links and dojo id (Chinese, English) |
| `web/index.html`, `web/js/hub.js` | The course home |
| `web/dojo.html`, `web/js/app.js` | The dojo editor (`dojo.html?d=<id>`) |
| `web/js/dojos/<id>.js`, `<id>.en.js` | Each dojo's lessons, tiered hints and per-failure hints |
| `course/dojos/<id>/` | Each dojo: `dojo.json` (language), `starter/` code, `tests/` per level, `reference/` solution (**spoilers**) |
| `course/shared/<lang>/` | Test helpers: `fail()`, `say()`, the timeline |
| `content/epNN/` | Each episode's video, chapters and lab page (generated by `python3 dev/sync_content.py`) |
| `dev/check.ts`, `dev/mutations.ts` | `npm run check`: the reference passes every level, the starter passes none, and typical mistakes are caught by the right level |
